# Xuanhuan Earth 0.7.0-alpha.11

## Target

- Minecraft 26.1.2
- NeoForge 26.1.2.124
- JDK 25
- License: `AGPL-3.0-only`
- Artifact: `xuanhuan-earth-neoforge-26.1.2-0.7.0-alpha.11.jar`

## Settlements: real variety

Every site now rolls its own palette and layout from the world seed mixed with its exact
origin, so two villages in the same world no longer look identical.

- **5 palettes**: spruce, birch, mossy stone, deepslate, stone brick, dark oak, bamboo,
  sandstone. The pool is chosen from the local climate (cold, dry, forest, temperate).
- **4 layouts**: `CROSS` (buildings around a plaza), `STREET` (a row along one road),
  `HALL` (one large hall plus wings), `RING` (huts around a well).
- Verified in a live server: six spirit spring villages produced 2 palettes and all 4
  layouts across 6 sites.

### Two more settlement types

The catalogue already listed `mountain_spirit_shrine` and `spirit_beast_keeper_camp` but
neither generated. Both are now real features with their own worldgen entries:

- **Mountain Spirit Shrine** — a three-step stone platform with an altar, corner braziers
  and a keeper hut. Rarer than the others.
- **Spirit Beast Keeper Camp** — a fenced spirit-soil pen with grass, a keeper tent and a
  supply shed stocking spirit grass and beast seals.

### Density

Rarity filters went from 180/220/260 chunks to 720/900/1100 (new types 780/950). Settlements
are now roughly 14-19 km apart instead of a few hundred blocks.

### The dead array core

Settlements used to place a lone `spirit_array_core`. A core only becomes a working array
when surrounded by four spirit soil arms and four corner focus blocks, so the placed block
could never form and looked meaningful while doing nothing. Workshops now build the complete
array, and the shrine altar uses one on top of a spirit vein node.

## Creature models rebuilt

The five beasts were re-authored from a single part/box spec that generates geometry, UVs
and the texture together, so the model and its texture can no longer drift apart.

- Fox: separate muzzle, jaw, inner-ear, crest and three-segment tail; added a neck block so
  the head no longer merges into the torso.
- Wolf: ruff, spine ridge, chest, segmented tail, collar gem, real ears.
- Goat: ram-style horns curling back in three segments instead of straight antlers, a beard,
  hoof blocks and a brighter palette.
- Turtle: shallow dome with a head that projects past the rim and a neck bridging it to the
  shell; splayed flippers.
- Crane: layered wing feathers, crest, neck, tail plumes.

## Verification

- `gradlew --offline build` and `verifyArcanaBalance` pass.
- Live dedicated server: all five settlement features place successfully via
  `place feature`; anchor NBT confirms `SettlementType`, `Layout` and `Palette` are stored
  per site.
- Models were rendered offline from four angles (front / side / top / iso) and inspected
  after each change; the preview tools live in `tools/preview_models.py`,
  `tools/preview_views.py` and `tools/write_models.py`.
- Not yet verified in game: how the rebuilt models look under real lighting, and whether the
  new layouts feel right when walked through.

This is an in-development prerelease.
