## Beast models: proportion pass

The previous pass fixed part names but not proportions. This one is driven by what the
four-view renders actually showed.

### What was wrong

- The preview tool's "front" view was silently rendering each animal's back, because
  Minecraft models face -Z and the camera looked down +Z. Fixed: the front view now uses a
  180 degree yaw, so every judgement after this point is against the real face.
- Fur textures were a single flat colour with +/-20 noise, so every creature rendered as a
  pale blob with no readable structure.

### What changed

- **Two-tone fur**: dorsal half darkened, ventral half lightened, plus a dark border on each
  face. This is what makes a Minecraft mob legible at 16 px.
- **Fox and wolf**: head raised and pushed forward with a neck block, so the head clears the
  chest instead of being hidden behind it. Wolf tail root raised so the tail no longer stands
  vertical.
- **Goat**: horns rebuilt as three flat sibling segments sweeping backward. Nesting them
  compounded each rotation and pushed the horn tips above the animal's back.
- **Turtle**: shell lowered and widened, head lifted above the rim with a neck bridge, so the
  head and flippers are visible from the side.
- **Crane**: neck rebuilt as a real S-curve (lower segment forward, upper segment back),
  wings tucked closer to the body, legs shortened.
- Palettes darkened for fox, turtle and crane so the shading has range to work with.

### Automated checks

Two new tools keep this from regressing silently:

- `tools/check_proportions.py` asserts head length vs torso, head overhang past the chest,
  head height, leg thickness and total height/length ratio. All five beasts pass.
- `tools/check_eyes.py` asserts every emissive eye pixel lands inside the head's front-face
  UV rectangle. All five pass.

## Preview sheets

Four-view sheets (front / side / top / iso) are written to:

```
D:\Codex\WORKSPACES\Projects\mc-agent\earth-series\xuanhuan_earth\tmp\model-views\<name>_sheet.png
```

Regenerate with `python tools/preview_views.py` from the repository root.
