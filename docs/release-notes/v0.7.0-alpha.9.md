# Xuanhuan Earth 0.7.0-alpha.9

## Target

- Minecraft 26.1.2
- NeoForge 26.1.2.124
- JDK 25
- License: `AGPL-3.0-only`
- Artifact: `xuanhuan-earth-neoforge-26.1.2-0.7.0-alpha.9.jar`

## Version line change

The mod now targets the same `MC 26.1.2 / NeoForge 26.1.2.124` line as `earth_on_minecraft` 0.1.16 and `earth_human` 0.1.20, so the three mods can be installed together again. The module directory is still named `neoforge-26.2`; the artifact and dependency ranges follow 26.1.2.

## Arcane energy contract v1

- New **Spirit Stone** item: a stack-size-1 carrier that stores 0-120 AEU of field charge in a persistent data component. Right-click charges it from the local qi field, sneak-right-click releases it as mana.
- `SpiritFieldLedger` is now the single conversion path between the 0-100 field scale and AEU. Spirit stones and meditation both go through it, so field level is never written as AEU.
- Field depletion is now debited only for the energy actually absorbed. Exposing 100 field levels at 8% absorption costs 8 levels instead of 100.
- Talismans seal 24 AEU when drawn at the Talisman Table, and settlement chests stock sealed talismans. An unsealed talisman is rejected at plan time and is not consumed.
- Spell graphs are data-driven JSON under `data/xuanhuan_earth/spell_graph`, validated per file with whitelisted node and source enums. Bad definitions are rejected individually and logged.
- `SpellGraphLoader` is now registered on the game event bus; it previously never loaded on a real server.

## Settlements

- Wandering markets, spirit spring villages and sect frontier outposts now place their own talisman tables, alchemy furnaces, array cores, spirit vein nodes and stocked barrels.
- Residents carry the `earth_on_minecraft:cultivation_settlement` profile and role keys so the Earth on Minecraft settlement board can index them when both mods are installed.

## Verification

- `gradlew --offline build` and `verifyArcanaBalance` pass.
- Dedicated server on MC 26.1.2 / NeoForge 26.1.2.124 starts clean and logs `Loaded 5 xuanhuan settlement definitions` and `Loaded 2 spell graph definitions`.
- Not yet verified in game: client world entry, right-click charge/release, death clone, relog, and live `/reload` of a broken spell graph.

This is an in-development prerelease.
